# T12. Овца бродит, пока идёт код

**Область:** Геймплей · **Размер:** S · **Не брать одновременно с:** T10

## Что сделать
Овца (`SheepObject`, добывается топором) сейчас стоит. Пусть медленно бродит в радиусе ~2 тайлов от точки появления:
шаг к случайной точке суши, пауза 2–4 с. **Время в мире идёт только пока выполняется код** (как у врагов: часы
`EnemyManager` запускаются по `LuaSandbox.OnRunningChanged(true)`), между запусками овца стоит.

Обязательно:
- позиция — через `ResourceObject.SetPosition`, и `ObjectManager` должен узнать о смене тайла (объекты хранятся
  по тайлам; если бакет не обновляется — добавить метод `ObjectManager.Move(obj, newPosition)`);
- не заходить в воду, в коллайдеры, на головоломки (`PuzzleManager.GetPuzzleAt`) и в лагеря врагов;
- случайность — от seed карты и id овцы (повторяемость), не `UnityEngine.Random` без seed.

Lua: `findObjects("sheep")` возвращает текущие `x`/`y`; если овца отошла, `mine(sheep)` даёт обычную ошибку «too far».

## Файлы
