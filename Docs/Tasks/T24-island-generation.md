# T24: Остров с биомами и события карты посреди забега

Размер: **M**. Область: генерация карты, головоломки. Ведёт: Claude (зона основной разработки).

## Что сделать

Генерация в духе Don't Starve, но **конечная**: каждый забег — один остров со своими биомами, вокруг океан.
Решения автора (2026-10-27): **сплошной остров** (изрезанный берег, озёра внутри, биомы — пятна Вороного без
перешейков), **свой цвет земли у каждого биома**, посреди забега появляются **головоломки (события карты)**,
место под них **резервируется заранее**.

### A. Остров (`Scripts/Map`)

- `IslandLayout` — чистый статический класс (EditMode-тесты), без `UnityEngine.Random` / `Mathf.PerlinNoise` с
  `seed * 0.001`: смещения шума — из `System.Random(seed)`.
  - Высота = fBm-шум (октавы из конфига) − радиальный спад от центра (форма острова, `islandFalloff`,
    `islandFalloffPower`), плюс искажение спада низкочастотным шумом, чтобы берег не был кругом.
  - Порог воды подбирается по **перцентилю**: доля суши = `landFraction` (по умолчанию ~0.5) — размер острова
    стабилен при любом seed.
  - Кольцо `borderWater` тайлов у края карты — всегда вода.
  - Оставляется только **самая большая связная** (4-связность) область суши; мелкие островки → вода
    (на них нельзя дойти — там не должно быть ресурсов и головоломок). Озёра внутри остаются.
  - Результат: `bool[,]` суша/вода (или `TileType[,]`).
- `MapGenerationConfig`: новые поля острова (`landFraction`, `islandFalloff`, `islandFalloffPower`,
  `coastNoiseScale`, `coastWarp`, `octaves`, `borderWater`); `waterThreshold` больше не используется
  (оставить поле с пометкой `[Obsolete]`-комментарием, сериализацию не ломать).
- `TilemapGenerator.GenerateGround` строит карту через `IslandLayout`.
- `BiomeMap.Generate(config, land, seed)`: центры Вороного берутся **только на суше**; вода = биом −1
  (`GetBiome` → null). Каждый биом по-прежнему встречается хотя бы раз.

### B. Цвет земли биома

- `Biome.groundTile` (`TileBase`, пусто = `MapGenerationConfig.grassTile`). `TilemapGenerator` ставит в
  `groundTilemap` тайл биома.
- `LandRuleTile : RuleTile` (`Scripts/Map`) — соседом «This» считает **любой** `LandRuleTile`, поэтому между
  биомами нет береговой кромки (жёсткий шов цвета, кромка только у воды).
- Ассеты (через Unity MCP, не YAML): `Assets/_Game/Tiles/LT_Color1..5.asset` — копии правил `RT_Grass` со
  спрайтами `Tilemap_colorN_k` из Tiny Swords; `grassTile` в конфиге → `LT_Color1`; биомам Лес / Луг / Скалы —
  разные цвета.

### C. События карты посреди забега (`Scripts/Puzzles`)

- `PuzzleGenerator` в начале забега **резервирует места для всех типов** (`PuzzleTypes.All`, открытых и
  закрытых) — с теми же правилами и тем же seed, что сейчас, — и сразу строит только открытые. Остальное —
  `PuzzleSlot` {тип, область, позиция, вид задачи у обелиска, seed раскладки} в списке ожидания.
- `PuzzleSpawner` (plain, `IDisposable`, создаётся в `Level` после `PuzzleManager`, только в Run) подписан на
  `UnlockRegistry.OnUnlocked`: при `UnlockKind.MapEvent` строит ждущие места этого типа, если **вся** область с
  полем ни разу не была открыта (`IFogProvider.IsExplored == false`) и в ней нет врагов. Иначе ищет новое место
  так же, как при старте (суша, неоткрыто, далеко от лагерей и других головоломок); не нашлось — предупреждение.
- После постройки — `PuzzleManager.Register`, `Physics2D.SyncTransforms`, уведомление игроку
  («На неоткрытой части острова появилось: X»), объекты карты под областью убираются.
- Строит то же, что генератор при старте: один код размещения, без копий.

## Критерии готовности

- [ ] Каждый забег — один остров, окружённый водой; доля суши ≈ `landFraction`; нет недостижимых островков.
- [ ] Биомы различимы по цвету земли, между ними нет береговой кромки.
- [ ] Одинаковый seed → тот же остров, биомы, объекты, головоломки (тесты).
- [ ] Достижение, открывшее событие посреди забега, сразу ставит его головоломки в неоткрытую часть острова;
      `findObjects("puzzle")` видит их, когда игрок дойдёт.
- [ ] Лагерь (хаб) по-прежнему строится (спавн на суше), портал забега находит место.
- [ ] EditMode: `IslandLayoutTests` (детерминизм, доля суши, край — вода, одна связная область),
      тест резерва мест и постройки по открытию. Все старые тесты зелёные.

## Не входит

Перешейки между биомами, новые объекты биомов, особые места (set pieces), ресурсы/лагеря посреди забега.
