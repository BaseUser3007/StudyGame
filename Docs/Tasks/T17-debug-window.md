# T17. Окно отладки в редакторе

**Область:** Инструменты · **Размер:** S · **Не брать одновременно с:** —

## Зачем
Чтобы проверить свою задачу, сейчас нужно честно пройти несколько дней. Нужен инструмент тестировщика (только в редакторе).

## Что сделать
`EditorWindow` «CodeRogue/Debug» (работает в Play Mode, в сборку не попадает — папка `Scripts/Editor`):
- выдать предмет (выпадающий список всех `ResourceItem`, количество) в инвентарь забега / в склад лагеря;
- энергия: заполнить / обнулить; здоровье: заполнить / −10; закончить день;
- открыть: команду / конструкцию / рецепт / постройку хаба / событие карты (через `UnlockRegistry`), «открыть всё» — без записи
  в сохранение, если это возможно, иначе с предупреждением «пишет в meta_progress.json»;
- телепорт игрока: к ближайшей головоломке / лагерю / клику по карте;
- выполнить достижение по id.

Ссылки брать через публичные свойства `Level` (`Level.Enemies`, `Level.Puzzles`, `Level.AchievementTracker`…). Если нужного нет
(энергия, инвентарь, день — сейчас это локальные переменные в `Level.Awake`), добавить **только** публичные свойства-геттеры
в `Level.cs` (горячий файл) — без изменения порядка инициализации. Телепорт — новый метод `PlayerCommandExecutor.Teleport(tile)`
(ставит позицию, `Physics2D.SyncTransforms`, `PlayerEventBus.PublishPlayerMoved`).

## Файлы
- новый `Scripts/Editor/DebugWindow.cs`
- `Scripts/Core/Level.cs` (горячий — геттеры), `Scripts/Player/PlayerCommandExecutor.cs` (метод `Teleport`)
