# T22. Библиотека кода: копировать и вставить через буфер обмена

**Область:** UI · **Размер:** S · **Не брать одновременно с:** —

## Зачем
Игроки делятся решениями (чат, форум). Сейчас код из библиотеки (`code_library.json`) нельзя вынести из игры одним действием.

## Что сделать
В панели библиотеки (`CodeLibraryPanel`, выдвижная справа):
- у каждой записи кнопка **Copy** — в буфер обмена (`GUIUtility.systemCopyBuffer`) текст вида
  `-- CodeRogue: <Title>` + код;
- кнопка **Paste** вверху панели — читает буфер: если первая строка `-- CodeRogue: <Title>`, создаёт запись с этим заголовком
  (заголовок проверить `LuaIdentifierValidator`, неверный → сделать валидным, как при открытии окна), иначе — с заголовком `Pasted`;
  пустой буфер / слишком длинный текст (> 20 000 символов) — уведомление с причиной.
- Короткое уведомление «Copied» / «Saved: X».
