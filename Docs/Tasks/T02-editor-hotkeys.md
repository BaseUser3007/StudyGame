# T02. Горячие клавиши редактора кода

**Область:** UI · **Размер:** S · **Не брать одновременно с:** T04 (оба правят `CodeEditor.cs`)

## Что сделать
Пока поле кода в фокусе (фокус получен кликом мыши — это правило не менять):
- **Ctrl+Enter** — то же, что кнопка Run (если код уже выполняется — Stop);
- **Ctrl+/** — закомментировать / раскомментировать текущую строку или все выделенные (`-- `);
- **Ctrl+D** — дублировать текущую строку.

Комбинации не должны пробрасываться дальше (камера, навигация UI). Существующие Ctrl+Space (автодополнение), Tab, Enter
в окне автодополнения работают как раньше.

## Файлы
- `Scripts/UI/Elements/CodeEditor.cs` — обработка клавиш (рядом с `ctrl && KeyCode.Space`); правки текста только через
  `ReplaceRange` / `InsertText` (см. CLAUDE.md «Code editor internals» — про `_pendingCursor`)
- для Ctrl+Enter: событие из `CodeEditor` → окно → `CodeEditorManager` (горячий файл: одна подписка рядом с
  `_topBar.OnRunRequested`), запуск тем же путём, что и кнопка Run
- в справку (`CommandHelp`) или подсказку кнопки Run — строка про сочетания (через `Loc`, свой раздел `LocRuT02.cs`)

## Готово, когда
- [ ] Ctrl+Enter запускает код из главного окна и из вспомогательного окна (запускается всё, как кнопкой Run).
- [ ] Ctrl+/ и Ctrl+D корректно работают с многострочным выделением; подсветка, номера строк и цены строк обновляются.
- [ ] В лагере (код не выполняется) Ctrl+Enter ничего не делает.
- [ ] Камера не двигается при нажатиях.
