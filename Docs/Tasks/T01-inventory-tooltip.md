# T01. Подсказка над слотом инвентаря

**Область:** UI · **Размер:** S · **Не брать одновременно с:** —

## Зачем
В нижней панели инвентаря видны только иконка, число и полоска прочности. Новичок не знает, как предмет
называется в Lua (`craft("axe")`, `eat("berries")`) и что делает еда.

## Что сделать
При наведении мыши на непустой слот показывать небольшую подсказку над слотом:
- название предмета (`ResourceItem` — отображаемое имя через `Loc.T`) и **имя для кода** моноширинным шрифтом (`itemId`);
- количество; у инструментов — прочность `текущая / макс`;
- у еды (`FoodItem`) — «+N энергии», «+N здоровья»;
- номер слота (1-based — так его принимает `drop(slot)` и `eat(slot)`).

Подсказка исчезает при уходе мыши, не перехватывает клики и не берёт фокус.

## Файлы
- `Scripts/UI/Elements/InventoryBar.cs` (класс `SlotView`), `UI/GUI/InventoryBar.uss`
- новый раздел перевода `Scripts/Localization/LocRuT01.cs` + строка в `LocTablesRu.cs`

## Готово, когда
- [ ] Подсказка появляется над любым непустым слотом и не выходит за край экрана.
- [ ] Пустой слот — без подсказки.
- [ ] Тексты переведены (RU/EN), имя для кода не переводится.
- [ ] `picking-mode` подсказки — Ignore; клики по панели работают как раньше.

## Как проверить
Play Mode → Start Run → `obtain("stick")` → навести на слот. Скрафтить топор — видна прочность.
