# T25: Стартовая платформа и одна попытка на головоломку

Размер: **M**. Область: головоломки, Lua-конвейер, UI. Ведёт: Claude (зона основной разработки).

## Механика (решения автора, 2026-10-27)

1. У каждой головоломки (обелиск, лабиринт, плиты) есть **стартовая платформа** — тайл:
   - лабиринт — тайл входа (внутрь, минуя его, не попасть);
   - плиты и обелиск — тайл вплотную к области со стороны подхода (суша, проходимый, не на другой головоломке).
2. Игрок встал на платформу (`PlayerEventBus.OnPlayerMoved`) → головоломка **начинается**. Игрок двигается
   только кодом, поэтому это почти всегда посреди запуска: **запуск прерывается** (как Stop — `pcall` его не
   поймает), энергия не возвращается, но **запуск дня не тратится**. Если кода нет (телепорт из окна Debug) —
   просто старт без прерывания.
3. При старте — **модальная карточка**: название, что сделать, награда, «Одна попытка: следующий запуск.
   Не решите — головоломка исчезнет». Тот же текст коротко дублируется в лог запуска.
4. **Попытка — следующий запуск кода.** Решена в нём → награда (как сейчас). Запуск закончился без решения
   (конец кода, ошибка компиляции/выполнения, нехватка энергии, Stop, запрет конструкции) → **провал**:
   головоломка исчезает (объекты, стены, туман-изгородь, регистрация в `PuzzleManager`), уведомление.
5. Одна активная головоломка за раз: пока есть начатая, чужие платформы не срабатывают.
6. До старта головоломка не решается: плиты не нажимаются, центр лабиринта не засчитывается, `solve()`
   отвечает ошибкой. Решённая головоломка остаётся на месте (как сейчас), её платформа больше не срабатывает.
7. Выход через портал / смерть во время активной — ничего особенного (сцена перезагружается).

## Состояния

`PuzzleState`: `Waiting` (не начата) → `Armed` (начата, ждёт запуск-попытку) → `Attempt` (идёт запуск-попытка)
→ `Solved` или `Failed` (исчезла). Начата вне запуска → сразу `Armed`. Начата посреди запуска → `Armed`,
текущий запуск прерывается; следующий `OnRunningChanged(true)` → `Attempt`; `OnRunningChanged(false)` в
`Attempt` без решения → `Failed`.

## Разделение работы

**A. Головоломки (gameplay-programmer):** `PuzzleStructure` — `State`, `StartTile`; генератор ставит
платформу (визуал — runtime-квадрат как у плит, свой цвет; `PuzzleConfig.startPlatformPrefab` необязателен),
она входит в занятую область (резерв мест T24 тоже); `PuzzleManager` — `ActivePuzzle`, события
`OnPuzzleStarted(PuzzleStructure)`, `OnPuzzleFailed(PuzzleStructure)`, `GetBriefing(puzzle)` → `PuzzleBriefing`
{Title, Description, Reward} (тексты через `Loc`), `Remove(puzzle)` (уничтожить объекты, снять изгородь
тумана — `FogOfWarSystem.RemoveHedgeArea`, убрать из списков); гейты решения (п. 6); жизненный цикл попытки
по `LuaSandbox.OnRunningChanged`. Прерывание — через интерфейс `IPuzzleRunControl { bool IsRunning; void
InterruptForPuzzle(); }` (Core); пока Level передаёт временную реализацию на `LuaSandbox.Stop()`.

**B. Lua (lua-systems-programmer, после A):** `LuaSandbox : IPuzzleRunControl` — `InterruptForPuzzle()`
останавливает запуск как `enterPortal` (`EnergyMeter.Halt` + отмена), итог `GameEventBus.RunTagPuzzle`
(`"puzzle"`, новый тег), `DayCycle` такой запуск не засчитывает; `puzzle()` — поля `state`
(`"waiting"/"armed"/"attempt"/"solved"`), `startX/startY`; `solve()` до попытки — `nil, "puzzle is not started —
step on its start platform"`; `findObjects` — `startX/startY`; `check` на платформе — `type`/`structure`
`"start_platform"` + `puzzle`; `LuaErrorExplainer` — строка про новую ошибку.

**C. UI (ui-programmer, после A):** `PuzzleBriefingPopup` (шаблон в `RunScreens.uxml` рядом с `UnlockPopup`,
мышиный, кнопка «Понятно») по `PuzzleManager.OnPuzzleStarted`, показывается после окончания прерванного
запуска; строка в RunLog; уведомление о провале. Индикатор в TopBar: «Головоломка: попытка — следующий запуск».

**D. Документация (game-designer, параллельно):** GameDesign §10.4 — новая механика.

## Критерии готовности

- [ ] Наступил на платформу посреди кода → запуск прерван, запуск дня не потрачен, карточка с описанием.
- [ ] Следующий запуск решил → награда; не решил (любой исход) → головоломка исчезла, уведомление.
- [ ] До старта плиты/центр лабиринта/`solve()` не работают; одна активная головоломка за раз.
- [ ] Головоломки, появившиеся посреди забега (T24), тоже с платформой.
- [ ] EditMode-тесты жизненного цикла, все старые тесты зелёные (поправить ожидания там, где решение
      раньше шло без старта).
