# T06. Всплывающие «−5» у полосы энергии

**Область:** UI · **Размер:** S · **Не брать одновременно с:** —

## Что сделать
Во время выполнения кода энергия уходит мелкими порциями, и игрок не видит, что дорого. Рядом с полосой энергии
в `TopBar` показывать всплывающие числа: «−2», «−13» (крупные траты — заметнее), «+6» зелёным (еда, награды).
Мелкие траты одного кадра/короткого окна (~0,25 с) суммировать, чтобы не было «дождя» из −1. Числа плывут вверх и гаснут за ~1 с.

Источник — `UIEventBus.OnPlayerEnergyChanged(current, max)` (разница с прошлым значением). Изменение максимума в начале дня
(`SetMax`) — не показывать как трату.

## Файлы
- `Scripts/UI/Elements/TopBar.cs`, `UI/GUI/TopBar.uss` (анимация — `experimental.animation` или пошаговое изменение стиля по `schedule`)

## Готово, когда
- [ ] Цикл `for i = 1, 10 do harvest() end` даёт несколько суммированных чисел, а не 30 отдельных.
- [ ] Начало нового дня не показывает «−»/«+» от смены лимита.
- [ ] Числа не перехватывают мышь (`picking-mode: ignore`).
