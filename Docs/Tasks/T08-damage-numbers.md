# T08. Цифры урона над врагом и игроком

**Область:** Визуал · **Размер:** S · **Не брать одновременно с:** T07

## Что сделать
При ударе показывать над целью всплывающее число урона: белое над врагом, красное над игроком; плывёт вверх и гаснет
за ~0,8 с. Объекты — из маленького пула; текст — `TextMeshPro` (world space) или спрайтовые цифры (без uGUI Canvas).

Источники:
- урон игроку — `EnemyManager.OnPlayerAttacked(Enemy, float damage)`;
- урон врагу — событие из `Enemy` / `CombatService` (если его нет — добавить `event`, логику боя не менять).

## Файлы
- новый `Scripts/Visual/DamageNumbers.cs`, отписка в `Dispose`/`OnDestroy`
- `Scripts/Core/Level.cs` (горячий) — создать и передать `EnemyManager` через `Initialize`
- при необходимости `Enemy.cs` / `CombatService.cs` — только новое событие

## Готово, когда
- [ ] Бой с гоблином: числа над обоими участниками; после 50 ударов в иерархии нет мусора (пул).
- [ ] Числа над объектами, но под туманом; если враг под туманом — число не показывается.
