# T04. Клик по ошибке в логе → переход к строке

**Область:** UI · **Размер:** S · **Не брать одновременно с:** T02

## Что сделать
В логе главного окна (`RunLog`) ошибка показывается как «Line N in Main» (`LuaErrorExplanation.Window`, `.Line`).
Сделать эту строку кликабельной: клик открывает/поднимает нужное окно (главное или вспомогательное с этим заголовком),
прокручивает к строке N и ставит туда курсор (выделяет строку), фокус поля — как при клике мышью.

## Файлы
- `Scripts/UI/Elements/RunLog.cs` — событие `OnGoToLineRequested(window, line)`
- `Scripts/UI/Elements/CodeEditor.cs` — метод «перейти к строке» (через `_pendingCursor`/`SelectRange`, см. квирк в CLAUDE.md)
- `Scripts/UI/CodeEditorManager.cs` (горячий) — найти окно по заголовку и вызвать переход
- `LocRuT04.cs`, если появятся новые тексты

## Готово, когда
- [ ] Ошибка в главном окне: клик → курсор на строке ошибки.
- [x] Ошибка во вспомогательном окне (`function Title()`): номер строки учитывает сдвиг обёртки (он уже посчитан в `LuaErrorExplainer`).
- [x] Окно закрыто/переименовано — клик ничего не ломает.
