# T03. Поиск в справке по командам

**Область:** UI · **Размер:** S · **Не брать одновременно с:** —

## Что сделать
В окне справки (`CommandHelp`, кнопка Help в верхней панели) добавить поле поиска сверху:
фильтр по имени команды, сигнатуре и описанию (без учёта регистра, на текущем языке), также по методам списков
(`getNear`, `where`…) и конструкциям языка. Пустой результат — строка «Nothing found».

Важно: поле поиска — текстовое, а клавиатура в игре по умолчанию «глотается». Оно должно получать фокус только кликом
мышью (так же, как поля кода — см. CLAUDE.md, раздел UI, и `PlayerEventBus.OnUIFocused`), и пока в нём печатают — камера не двигается.

## Файлы
- `Scripts/UI/Elements/CommandHelp.cs` (+ его стили в USS, где они лежат)
- `LocRuT03.cs` + строка в `LocTablesRu.cs`

## Готово, когда
- [ ] Ввод «move» оставляет `move`, `moveTo`; «урож»/«harv» — `harvest` на соответствующем языке описаний.
- [ ] Закрытые команды не появляются в результатах (справка строится из реестра открытых).
- [ ] WASD в поле поиска не двигают камеру; Esc/закрытие справки снимает фокус.
