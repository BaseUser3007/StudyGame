## Этап 1. Открытие команд и конструкций языка

- [x] ★ `UnlockRegistry` — какие команды/конструкции доступны (из `MetaProgress`); стартовый набор задаётся
      в ScriptableObject.
- [x] ★ Закрытые команды не регистрируются в `LuaSandbox.RegisterCommands()` и не видны в справке,
      подсветке и автодополнении (всё это берётся из реестра `ILuaCommand` — фильтровать на входе).
- [x] ★ Блокировка конструкций языка: перед запуском токенайзер `EnergyInstrumenter` ищет закрытые
      ключевые слова (`for`, `while`, `repeat`, `function`…) и отказывает с понятным сообщением
      («цикл `for` ещё не открыт — …»). Окна-«классы» (доп. окна) — тоже открываемая возможность.
- [x] ★ Подсветка/справка показывают закрытые конструкции как недоступные (или скрывают).
      Справка: закрытые команды скрыты, конструкции — все, закрытые приглушённо с «locked»; подсветка —
      `CodeEditorTheme.lockedKeywordColor`; автодополнение не предлагает закрытые ключевые слова/шаблоны;
      при закрытых окнах-«классах» кнопка «+» скрыта, «Открыть» в библиотеке выключено.
      Всё перестраивается по `LuaSandbox.OnUnlocksApplied`.
- [x] ★ Всплывающее окно «Открыто: X» с объяснением, зачем это нужно, и примером кода.
      (`UnlockPopup` по `UnlockRegistry.OnUnlocked`, после окончания запуска, очередь; тексты конструкций —
      `LuaConstructGuide`. Описания команд пока по-русски — из `ILuaCommand.Description`.)
- [ ] ★ «Декомпиляция» (метафора): награда-открытие базовых команд, заменяющих готовую
      (`obtain` → `findObjects` + `moveTo` + `harvest`/`mine`). Всплывашка объясняет, из чего состояла
      готовая команда, показывает пример кода и сравнение цены по энергии. Готовая команда при этом
      остаётся доступной (дорогой).

## Этап 3. Мировая угроза и враги

- [ ] ★ День угрозы в `DayCycle` (из `RunModifiers`, по умолчанию 3): предупреждение за день,
      отображение в `TopBar`, поле в `getStatus()`.
- [ ] ★ Базовый класс врага (спрайты гоблинов из Tiny Swords, `DepthSortedSprite`, коллайдер),

- [ ] ★ Статические враги: генерируются вместе с объектами (лагеря у ценных мест/головоломок),

      по тайлам, как `PlayerCommandExecutor`).

- [ ] ★ Враги наносят урон `PlayerHealth` (радиус и перезарядка атаки), у врагов есть своё здоровье.
- [ ] ★ Бой: команда `attack([x, y] | obj)` (с ценой энергии), урон зависит от оружия; оружие —

- [ ] ★ Добыча с врагов (лут через `ResourceVariant.loot`) и достижения за победу над врагом.
- [ ] Разные враги (лучник на расстоянии, сильный страж у головоломки).
